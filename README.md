# CrickNiro 🏏

**CrickNiro** is an innovative, browser-based digital adaptation of the beloved schoolyard hand-cricket pastime, meticulously tailored for the vibrant youth and university culture of Bangladesh. It resurrects the authentic, high-banter atmosphere of rooftop and alleyway matches by fusing local nostalgia with modern, high-performance web architecture.

---

## 🌟 Core Features & Game Mechanics

### 1. The 15-Second Pressure Cooker
* **High-Stakes Timer:** Every player faces a strict 15-second countdown timer per delivery, forcing split-second decisions and panic-driven plays.
* **Undo/Redo Flexibility:** Players can change their minds, switch their choices, and bluff their opponents within the 15-second window before locking it in.
* **AI Fallback:** If a player times out or gets distracted, the system automatically selects an option to keep the game moving.

### 2. Granular Finger-Orientation Input UI
* **Simple Taps (5 & 6):** Direct, instant input for maximum values.
* **Visual Cards (1 through 4):** Custom-drawn visual cards representing traditional schoolyard finger orientations (concealing or displaying specific fingers).

### 3. Psychological Warfare (Voice-Chat Integration)
* **Real-Time WebRTC Audio:** Bypassing complex computer vision, CrickNiro features integrated voice channels allowing friends to engage in uninterrupted friendly banter, sledging, and tactical trash talk just like real *adda* culture.

### 4. Advanced Single-Player AI & Match Formats
* **Custom Configurations:** Play anything from a quick 2-over sprint to a full 50-over ODI or a legendary Test Match, with customizable wickets (up to 10).
* **Adaptive Learning AI:** In Test conditions, the AI intelligently rotates the strike with singles and doubles rather than reckless power-hitting, gradually studying and adapting to the player's historical tendencies over time.
* **Difficulty Tiers:** Easy, Medium, and Hard tiers with global category leaderboards.

### 5. Session Control & Social Architecture
* **Seamless AI Persistence:** Play and resume single-player matches whenever you want.
* **Democratic Multiplayer Controls:** Live 1v1 pauses and restarts require mutual consent from both players, backed by a strict forfeit "hard-cut" policy for disconnections.
* **Frictionless Social Loop:** Challenge strangers via direct private link-sharing, add rivals as friends post-match, and send direct in-game lobby invites.

---

## 🚀 Getting Started (Planned Architecture)

As a modern web application designed for mobile-first accessibility in Bangladesh, CrickNiro is architected to run smoothly across standard 4G networks using a lightweight stack:
* **Frontend:** Responsive Web App / Progressive Web App (PWA) framework with Tailwind CSS styling.
* **Multiplayer & Voice:** Low-latency WebSockets (Socket.io) combined with WebRTC / Agora.io for voice channels.
